# Desafio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Rails local pra acompanhar um desafio de 75 dias com grupos de desafios simultâneos, onde só os vacilos são registrados.

**Architecture:** Hierarquia fixa `Project → Group → Challenge → Slip`. Só os vacilos (`Slip`) vão pro banco; "cumprido" é derivado (dia passado sem slip). Datas e métricas vivem nos models (`Project::Results`), controllers REST finos e aninhados, Turbo Stream como resposta ao marcar vacilo.

**Tech Stack:** Rails 8.1, Ruby 3.4, SQLite, Propshaft, importmap, Turbo, CSS puro, Minitest + fixtures, Capybara/Selenium (Chromium headless).

**Spec:** `docs/superpowers/specs/2026-10-16-desafio-design.md`

**Convenções (padrão 37signals):** métodos privados indentados abaixo de `private`; arrays com espaço interno (`[ :name ]`); `params.expect`; `status: :unprocessable_content` em form inválido; `status: :see_other` em redirect de destroy; strict locals (`<%# locals: (...) %>`) em toda partial.

**Datas nos testes:** todo teste que depende de "hoje" usa o helper `travel_to_day(Date.new(...))` (Task 1), que viaja pro meio-dia no fuso `America/Sao_Paulo`. A fixture principal começa em **2026-10-01**, e a maioria dos testes vive em **2026-10-12** (dia 12 de 75).

- [ ] **Step 5: Implementar**

Substituir `app/models/project.rb`:

```ruby
class Project < ApplicationRecord
  DURATION = 75

  validates :name, :starts_on, presence: true

  def ends_on
    starts_on + (DURATION - 1)
  end

  def days
    starts_on..ends_on
  end

  def day_number(date)
    (date - starts_on).to_i + 1
  end

  def status
    if Date.current < starts_on
      :upcoming
    elsif Date.current > ends_on
      :finished
    else
      :active
    end
  end

  def elapsed_days
    starts_on..[ Date.current, ends_on ].min
  end
end
```

`elapsed_days` não precisa de caso especial antes do início: um range `x..y` com `y < x` já é vazio.

class Challenge < ApplicationRecord
  belongs_to :group
  has_many :slips, dependent: :destroy

  delegate :project, to: :group

  validates :name, presence: true

  def status_on(date)
    if date > Date.current
      :future
    elsif slipped_dates.include?(date)
      :slipped
    else
      :kept
    end
  end

  private
    def slipped_dates
      @slipped_dates ||= slips.pluck(:day).to_set
    end
end

class Slip < ApplicationRecord

  validates :day, presence: true, uniqueness: { scope: :challenge_id }
  validate :day_within_project, :day_not_in_future, if: :day

      errors.add :day, "fora dos 75 dias do projeto" unless project.days.cover?(day)

    def day_not_in_future
      errors.add :day, "não pode ser no futuro" if day > Date.current

end

Criar `app/models/project/results.rb`:

```ruby
module Project::Results
  extend ActiveSupport::Concern

  def slips_count
    slips.count
  end

  def perfect_days
    return [] if challenges.none?

    slipped = slips.pluck(:day).to_set
    elapsed_days.reject { |day| slipped.include?(day) }
  end

  def slips_timeline
    slips.includes(:challenge).order(:day, :id)
  end
end
```
